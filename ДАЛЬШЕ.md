# Сейчас

**Бот уже написан.** Не создавайте заново.

## Чеклист

- [ ] Скопировать папку `cursor-telegram-bot` на ПК
- [ ] `copy .env.example .env` → `BOT_TOKEN`, `CURSOR_API_KEY`, `DEFAULT_REPO_URL`
- [ ] Проверка: `.\setup.ps1`
- [ ] Railway (бот без ПК): те же переменные → Deploy
- [ ] В Telegram: `/start` → пишите задачи текстом

## В Cursor на ПК

Откройте эту папку и напишите:

```
Помоги с текущим шагом из ДАЛЬШЕ.md
```

Агент **не** должен заново объяснять «как создать бота» — только помочь с вашим шагом.

Telegram и приложение Cursor **связывать не нужно** — это отдельные вещи.

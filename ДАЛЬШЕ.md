# Сейчас

Бот умеет скачивать **PDF из Telegram** и передавать содержимое в Cursor Cloud Agent.

## Как пользоваться PDF

1. Откройте бота → `/start`.
2. Отправьте PDF (можно с подписью-задачей).
3. Либо сначала PDF, затем текст: «сделай конспект», «внедри это ТЗ».
4. Агент получит извлечённый текст и скриншоты страниц.

## Чеклист запуска

- [ ] `copy .env.example .env` → `BOT_TOKEN`, `CURSOR_API_KEY`, `DEFAULT_REPO_URL`
- [ ] Локально: `pip install -r requirements.txt` → `python bot.py`
- [ ] Railway: те же переменные → Deploy
- [ ] В Telegram: отправьте PDF и задачу

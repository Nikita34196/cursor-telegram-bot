# Справка: папка на ПК

**Сначала откройте [ДАЛЬШЕ.md](./ДАЛЬШЕ.md)** — там один чеклист, без лишнего текста.

## 1. Скопируйте папку

Скопируйте **всю папку** `cursor-telegram-bot` на компьютер, например:

```
C:\Projects\cursor-telegram-bot
```

Внутри должны быть файлы:

```
bot.py
cursor_client.py
storage.py
sync_service.py
requirements.txt
.env.example
README.md
setup.ps1
Dockerfile
```

## 2. Откройте в приложении Cursor

1. Cursor → **File → Open Folder**
2. Выберите `cursor-telegram-bot`
3. В чате Cursor напишите:

> Помоги настроить .env и проверить бота. Потом подскажи деплой на Railway.

## 3. Настройте `.env`

```powershell
cd C:\Projects\cursor-telegram-bot
copy .env.example .env
notepad .env
```

Заполните:

| Переменная | Где взять |
|------------|-----------|
| `BOT_TOKEN` | [@BotFather](https://t.me/BotFather) → `/newbot` |
| `CURSOR_API_KEY` | [cursor.com/dashboard](https://cursor.com/dashboard) → API Keys |
| `DEFAULT_REPO_URL` | Ваш GitHub, например `https://github.com/Nikita34196/ocr-bot` |

## 4. Проверка на ПК (опционально)

```powershell
.\setup.ps1
```

Бот запустится локально. Для работы **24/7 без ПК** — деплой на Railway (см. `README.md`).

## 5. Деплой в облако (бот без вашего ПК)

После проверки попросите Cursor в терминале:

```powershell
# установите Railway CLI с https://docs.railway.app/guides/cli
railway login
railway init
railway variables set BOT_TOKEN=... CURSOR_API_KEY=... DEFAULT_REPO_URL=...
railway up
```

Или через сайт [railway.app](https://railway.app) → Deploy from GitHub.
